# 6G XL-MIMO Datasets

This project presents XL-MIMO datasets and interactive visualizations for wireless channel research.

## Ground-level XL-MIMO Dataset

Our ground-level dataset contains 4,780 simulated user trajectories across seven layouts and three propagation scenarios: stable LoS, stable NLoS, and edge transition. Generated with Sionna RT, it pairs complex CSI from a 64 x 64 physical antenna array with synchronized RGB, LiDAR, and position observations. The data support studies of near-field, spatially non-stationary channel evolution and multimodal long-horizon prediction.
